Inventory Manager

Turn supplier inventory files into Shopify updates, and see what is new or discontinued.

New here? How this tool works

Hide

The Run House sells shoes it does not physically stock, they ship from the supplier (dropship). This tool keeps Shopify in sync with what each supplier currently has, so the website never sells a shoe that is gone or misses one that is new.

1

Get the supplier file

For each brand, download or scrape its current inventory from the B2B portal. ASICS, Brooks, and ON use the Chrome "Auto Scrape" tool (links are in each card's Instructions). The others download a file directly.

2

Drop it in the brand card

Drag the file onto that brand's box. The tool reads it and lists the products it found, with a NEW badge on anything not yet on our Shopify.

3

Review, then Generate

Tick the products to include and press Generate Inventory. The tool compares your file against what is live on Shopify and flags three things: new products, new colorways, and items that vanished from the supplier (which get set to 0).

4

Download and import

Use the Downloads section to get a Shopify-ready CSV, then import it in Shopify admin. New products get their own CSV with tags and pricing already filled in.

What "live" means here

Instead of guessing from a saved list, the tool reads the real Shopify catalog, refreshed daily (and on demand with the Refresh button up top). It only ever looks at dropship inventory at the Needham location, so shoes stocked at the physical stores (Falmouth, Scituate, Walpole) are never touched. Before setting anything to 0, it shows you exactly what will change and asks you to confirm.

Colorway one color of a shoe model, eg "Clifton 9 Black" Handle a product's unique Shopify address, how a row finds its product Generate build the Shopify update file for the products you picked Discontinued a shoe the supplier dropped, set to 0 so it stops selling

How to Download Saucony Inventory:

  1. Go to Saucony B2B Portal
  2. Open the At-Once catalog for the season
    (e.g. Autumn Winter 2026 Performance)
  3. Export Catalog UPCs (.xlsx)
  4. Drag file here

Note: this replaces the old Needham Demo Inventory export. The Catalog UPCs file carries barcodes, MSRP and real sizes, so nothing needs uploading separately.
