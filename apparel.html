ON Apparel

Turns an ON apparel scrape into a Shopify inventory CSV. Apparel is separate from the footwear tool because the live-catalog side of that tool only knows about shoes, so nothing here reads or writes Shopify. You download a file and import it yourself.

This page never sets anything to 0. The footwear tool zeroes what falls out of a supplier feed, because those shoes are dropshipped from one known location. Apparel is not dropshipped yet, so a garment missing from a scrape means nothing here and no row is written for it. Only what is in the file gets exported.
